# WealthPath: The Financial Odyssey 🎲📈
### 15-Mark University Academic Financial Planning Board Game Kit & Interactive Engine

> **Academic Project Blueprint & Interactive Simulation Engine**  
> Developed for Undergraduate / MBA Personal Finance, Wealth Management, and Taxation Curriculums.

---

## 🌟 Overview

**WealthPath: The Financial Odyssey** is a comprehensive educational board game and interactive digital simulation designed to bridge the gap between abstract personal finance theory and practical life-cycle decision making. 

Modeled after Nobel laureate Franco Modigliani's **Life-Cycle Hypothesis** and Harry Markowitz's **Modern Portfolio Theory**, players navigate 40 years of adulthood across 32 sequential track spaces—traversing career launches, discretionary spending temptations, macroeconomic cycles, health shocks, property acquisitions, and retirement wealth drawdown.

---

## 🎯 Key Pedagogical Features

### 1. Sequential 32-Space Life-Cycle Board Track
- **Phase 1: Early Career (Age 22–26)** – Cash-flow baseline, 50/30/20 budgeting rule, first SIPs in equity index funds, avoiding revolving credit card debt.
- **Phase 2: Foundation & Family (Age 27–35)** – Marriage milestones, 3–6 month emergency liquid funds, family floater health insurance (Section 80D), Section 80C tax optimization.
- **Phase 3: Wealth Building & EMIs (Age 36–48)** – 20-year mortgage debt amortization, child education funds, bull/bear market rebalancing, debt prepayment spread analysis.
- **Phase 4: Pre-Retirement & Golden Years (Age 49–60+)** – Portfolio glide paths to reduce sequence-of-returns risk, will drafting and estate succession, systematic withdrawal plans (SWP), and debt-free retirement.

### 2. Balanced 15-Card Pedagogical Deck
- **5 Event Cards** – Exogenous shocks & windfalls (e.g., sudden hospitalizations, tech gadget breakdowns, unexpected performance bonuses).
- **5 Decision Cards** – Active financial trade-offs (e.g., term insurance vs. ULIPs, auto loan vs. public transit, mortgage prepayment vs. equity mutual funds).
- **5 Goal & Tax Cards** – Statutory optimizations (Section 80C PPF/ELSS, Section 80D mediclaim, Section 24(b) home loan interest, National Pension Scheme Tier 1).

### 3. Interactive Player Financial Ledger
- **5-Column Balance Sheet**: Real-time auditing of Cash in Hand, Liquid Savings (Emergency Fund), Investments (Equity/Gold/Debt), Liabilities/Loans, and Net Worth.
- **Live Ratio Telemetry**: 
  - Emergency Fund Ratio (target $\ge$ 3–6 months)
  - Debt-to-Income (DTI) Ratio (target $\le$ 40%)
  - Savings Rate ($\ge$ 20% surplus)
- **Currency Toggle**: Switch seamlessly between Indian Rupee (INR ₹) and US Dollar (USD $) modes.

### 4. AI Prototype Asset Studio
- Visual engineering prompts fine-tuned for Google Imagen 3, Midjourney v6, and DALL-E 3.
- Generates 2D flat vector board layouts, poker-sized card art, and retail box cover renders.

### 5. 15-Mark Examination Blueprint & Viva Voce Guide
- Formal 4-part grading rubric totaling 15 marks.
- Viva voce oral defense guide with high-frequency examiner questions and model answers.
- Printable, high-contrast A4 cut-out sheets for physical card stock and student ledger logs.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18.0.0 or higher recommended)
- npm or yarn

### Installation & Run

1. Clone the repository:
   ```bash
   git clone https://github.com/AaronG-092/wealthpath-financial-board-game.git
   cd wealthpath-financial-board-game
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Launch development server:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

4. Run lint and production build:
   ```bash
   npm run lint
   npm run build
   ```
